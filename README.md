# Dalton Babbs — Personal Website

This is my personal portfolio website, built to showcase my background, work experience, education, projects, and skills as a Software Engineer.

## Tech Stack

- [Next.js](https://nextjs.org) (App Router) with Turbopack
- [React](https://react.dev) & [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com) v4
- [lucide-react](https://lucide.dev) for icons

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Project Structure

- `src/app` – root layout and page
- `components` – section components (Hero, About, Work Experience, Education, Projects, Skills, Contact, Navbar, etc.)
- `hooks` – shared React hooks (e.g. scroll-reveal animations)
- `public` – static assets and images
